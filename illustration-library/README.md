# Three-Lanes · Lightweight Blueprint SVG Kit

**Visual reference:** the original Spring Petclinic commit diagrams, not the retired 50 detailed clipart-style illustrations.

Browse [gallery](./index.html) · [machine-readable catalog](./catalog.json) · [SVG source](./assets/).

## Rules for every AI

- Read real source changes **before** choosing a visual. This is an open component toolkit, **not** a closed set of permitted diagrams.
- Use flat 2D outlined browser, server, database, controller, calendar, clock and other shapes; light blue/green/red, no gradients, shadows, 3D machinery, bulky racks or thick arrows.
- Reuse individual SVG IDs, combine them, or create completely new primitives and diagrams whenever code requires. Never force unrelated code into an existing recipe.
- **Connectors 1.5–2.2px, compact outlined arrowheads of approximately 7px.** No thick triangles or labels touching paths.
- Light paper background with subtle 24px dots and 120px grid for full diagrams; standalone icons stay transparent.
- Maintain generous whitespace, clear labels (normally 11–16px), centered composition and logical flow. No overlap or clipping.
- Give each new SVG its own ID, title, description, viewBox and appropriate source explanation. The old 50 assets are removed from the main branch.
- Each learning step remains one changed code file and ≤100 instructional code/diff lines.

These icons are examples of style. A new diagram is allowed without prior approval or registration. The only mandatory requirements are source fidelity and visual quality.
