# Backend SVG asset folder

Drop previously created `.svg` diagrams here. Use a clear `viewBox`, self-contained SVG graphics and legible labels.

Connect them through `../visuals.json` using the immutable source SHA and the learning step ID. The shared engine should make meaningful SVG labels/icons clickable where a verified source-link mapping exists.

Keep a source-code link in `source-links.json`; do not invent real project code inside explanatory diagrams.
